# Is my battery compatible?

Omnibattery can automatically control the batteries below from Home Assistant. Find your exact model, prepare the connection it needs, and check its limit before you install.

| Brand / model | What you need | What control you get | Important limit | Guide |
|---|---|---|---|---|
| **Marstek Venus E v2** | Direct Modbus connection through an RS-485-to-TCP gateway or USB-to-RS-485 adapter. | Automatic control; solar readings only when its register map supplies them; hardware SOC limits. | Up to 2,500 W. Needs an RS-485 connection, not the battery's Ethernet address. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus E v3** | A reachable Ethernet address. | Automatic control; solar readings only when its register map supplies them; software SOC limits. | Up to 2,500 W. The LilyGo route does not support this model. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus A** | A reachable Ethernet address. Tell the wizard whether DC solar is connected. | Automatic control; solar readings when the selected map supplies them; software SOC limits. | Up to 1,500 W. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus D** | A reachable Ethernet address. Tell the wizard whether DC solar is connected. | Automatic control; solar readings when the selected map supplies them; software SOC limits. | 2,200 W; 2,500 W from EMS firmware 149. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus E with the v2 register map, via ESPHome / LilyGo** | A LilyGo RS-485 board running the supported ESPHome firmware, already added to Home Assistant with its stock entity names. | Automatic control; no MPPT solar telemetry; hardware SOC limits. | This route is not for Venus A, Venus D, or Venus E v3. | [ESPHome / LilyGo RS485](configuration/batteries/esphome-lilygo.md) |
| **Zendure SolarFlow 800, 800 Plus, or 800 Pro** | A stable local IP address and Zendure HEMS disabled. | Automatic control; no dedicated solar telemetry; device SOC limits. | 1,000 W charge, 800 W discharge. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Zendure SolarFlow 1600 AC+, 2400 AC Pro, 2400 AC+, 3000 Mix AC+, or 4000 Mix AC+** | A stable local IP address and Zendure HEMS disabled. | Automatic control; no dedicated solar telemetry; device SOC limits. | Same in both directions: 1,600 / 2,400 / 2,400 / 3,000 / 4,000 W. HEMS takes control back if it is enabled. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Zendure SolarFlow 4000 Mix Pro** | A stable local IP address and Zendure HEMS disabled. | Automatic control; dual MPPT solar telemetry; device SOC limits. | Up to 4,000 W both ways. HEMS takes control back if it is enabled. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Anker SOLIX Solarbank Max AC or XE AC** | Modbus TCP and **Third-Party Control** enabled in the Anker app. | Automatic control; no independent solar telemetry; hardware SOC limits. | One Modbus client at a time: no other integration can connect alongside Omnibattery. | [Anker SOLIX](configuration/batteries/anker.md) |
| **Anker SOLIX Solarbank 4 E5000 Pro** | Modbus TCP and **Third-Party Control** enabled in the Anker app. | Automatic control; independent solar telemetry; hardware SOC limits. | Close other Modbus clients before setup. | [Anker SOLIX](configuration/batteries/anker.md) |
| **Sessy Home Battery** | A reachable Sessy dongle and the credentials printed on it. | Automatic control; its PV reading is informational, not controller solar telemetry; software SOC limits. | 2,200 W charge, 1,700 W discharge. The first command after standby can be delayed. | [Sessy Home Battery](configuration/batteries/sessy.md) |
| **Hoymiles MS-A2 or HiBattery 1920 AC** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; no solar telemetry; software SOC limits. | 1,000 W per unit (MS-A2 up to 2,000 W, 1920 AC up to 6,000 W). | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Hoymiles HiBattery 4020 X** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; solar telemetry; software SOC limits. | Up to 2,500 W both ways. | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Hoymiles HiBattery 4020 AC** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; no solar telemetry; software SOC limits. | Up to 2,500 W both ways. | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Huawei SUN2000 inverter with LUNA2000** | A local Modbus TCP endpoint. Use Huawei Solar or enable direct Modbus writes; use a Modbus proxy when Huawei Solar already connects to the inverter. | Automatic control; solar and per-string telemetry when reported; software SOC limits with hardware cutoffs as a backstop. | Forced discharge is unavailable while solar strings are producing. | [Huawei SUN2000 + LUNA2000](configuration/batteries/huawei.md) |

## My battery is not listed

A supported model needs reliable local telemetry, charge and discharge control, and a safe idle command. See the [battery driver requirements](reference/driver-requirements-template.md) before requesting a new model, then [open a GitHub issue](https://github.com/ffunes/omnibattery/issues) with the model, firmware, connection method, and any vendor protocol documentation.
