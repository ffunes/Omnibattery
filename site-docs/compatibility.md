# Is my battery compatible?

Omnibattery can automatically control the batteries below from Home Assistant. Find your exact model, prepare the connection it needs, and check its limit before you install.

| Brand / model | What you need | What control you get | Important limit | Guide |
|---|---|---|---|---|
| **Marstek Venus E v2** | Direct Modbus connection through an RS-485-to-TCP gateway or USB-to-RS-485 adapter. | Automatic control; solar readings only when its register map supplies them; hardware SOC limits. | It needs an RS-485 connection rather than the battery's Ethernet address. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus E v3** | A reachable Ethernet address. | Automatic control; solar readings only when its register map supplies them; software SOC limits. | The LilyGo route does not support this model. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus A** | A reachable Ethernet address. Tell the wizard whether DC solar is connected. | Automatic control; solar readings when the selected map supplies them; software SOC limits. | Its model-specific power ceiling is lower than the Venus E ceiling. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus D** | A reachable Ethernet address. Tell the wizard whether DC solar is connected. | Automatic control; solar readings when the selected map supplies them; software SOC limits. | Its available power ceiling depends on the EMS firmware. | [Marstek Venus](configuration/batteries/marstek.md) |
| **Marstek Venus E with the v2 register map, via ESPHome / LilyGo** | A LilyGo RS-485 board running the supported ESPHome firmware, already added to Home Assistant with its stock entity names. | Automatic control; no MPPT solar telemetry; hardware SOC limits. | This route is not for Venus A, Venus D, or Venus E v3. | [ESPHome / LilyGo RS485](configuration/batteries/esphome-lilygo.md) |
| **Zendure SolarFlow 800, 800 Plus, or 800 Pro** | A stable local IP address and Zendure HEMS disabled. | Automatic control; no dedicated solar telemetry; device SOC limits. | Their discharge ceiling is lower than their charging ceiling. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Zendure SolarFlow 1600 AC+, 2400 AC Pro, 2400 AC+, 3000 Mix AC+, or 4000 Mix AC+** | A stable local IP address and Zendure HEMS disabled. | Automatic control; no dedicated solar telemetry; device SOC limits. | HEMS takes control back if it is enabled. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Zendure SolarFlow 4000 Mix Pro** | A stable local IP address and Zendure HEMS disabled. | Automatic control; dual MPPT solar telemetry; device SOC limits. | HEMS takes control back if it is enabled. | [Zendure SolarFlow](configuration/batteries/zendure.md) |
| **Anker SOLIX Solarbank Max AC or XE AC** | Modbus TCP and **Third-Party Control** enabled in the Anker app. | Automatic control; no independent solar telemetry; hardware SOC limits. | The battery accepts only one Modbus client session at a time. | [Anker SOLIX](configuration/batteries/anker.md) |
| **Anker SOLIX Solarbank 4 E5000 Pro** | Modbus TCP and **Third-Party Control** enabled in the Anker app. | Automatic control; independent solar telemetry; hardware SOC limits. | The battery accepts only one Modbus client session at a time. | [Anker SOLIX](configuration/batteries/anker.md) |
| **Sessy Home Battery** | A reachable Sessy dongle and the credentials printed on it. | Automatic control; its PV reading is informational, not controller solar telemetry; software SOC limits. | The first non-zero command can be delayed while the battery leaves standby. | [Sessy Home Battery](configuration/batteries/sessy.md) |
| **Hoymiles MS-A2 or HiBattery 1920 AC** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; no solar telemetry; software SOC limits. | The power envelope published by the battery can reduce the available power. | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Hoymiles HiBattery 4020 X** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; solar telemetry; software SOC limits. | The power envelope published by the battery can reduce the available power. | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Hoymiles HiBattery 4020 AC** | **MQTT Service** enabled in S-Miles Home, plus a local MQTT broker configured in Home Assistant and the complete device ID. | Automatic control; no solar telemetry; software SOC limits. | The power envelope published by the battery can reduce the available power. | [Hoymiles MQTT batteries](configuration/batteries/hoymiles.md) |
| **Huawei SUN2000 inverter with LUNA2000** | A local Modbus TCP endpoint. Use Huawei Solar or enable direct Modbus writes; use a Modbus proxy when Huawei Solar already connects to the inverter. | Automatic control; solar and per-string telemetry when reported; software SOC limits with hardware cutoffs as a backstop. | Forced discharge is unavailable while solar strings are producing. | [Huawei SUN2000 + LUNA2000](configuration/batteries/huawei.md) |

## My battery is not listed

A supported model needs reliable local telemetry, charge and discharge control, and a safe idle command. See the [battery driver requirements](reference/driver-requirements-template.md) before requesting a new model, then [open a GitHub issue](https://github.com/ffunes/Omnibattery/issues) with the model, firmware, connection method, and any vendor protocol documentation.
